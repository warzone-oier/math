本项目旨在对整个 OI 数学实现入门到入土级的梳理，体现各个知识点的普遍联系。

## 推荐阅读顺序

### 高等代数、组合、数论 $\star$

1. `【群】`标签的四个内容
2. `【环】（1）整数环` 和 `【环】（2）多项式环`
3. `【环】（3）多项式算法`（需要`【域】（1）复数域` 作为前置知识，最好和 `【分析】（3）无限微积分` 一起读）
4. `【组合】（1）二项式系数` 和 `【概率】概率期望`
5. `【环】（4）集合幂级数
6. `【组合】（2）组合符号化`（需要`【环】（4）集合幂级数`作为前置知识）
7. `【组合】（3）一维递推关系`（需要`【模】（3）线性变换与矩阵` 作为前置知识）
8. `【组合】（4）二维递推关系`
9. `【组合】（5）反演变换`

### 线性代数

顺着往下读就行，注意 `【模】（2）线性空间` 需要用到 `【环】（2）多项式环` 的定义和 `【分析】（3）无限微积分` 的例子。

### 分析学

1. `【分析】（1）极限和渐进`、`【分析】（2）有限微积分`
2. `【分析】（3）无限微积分`（最好和 `【环】（3）多项式算法` 一起读）
3. `【分析】（5）多元微积分`（需要 `【模】（7）计算几何` 作为前置知识）

### 组合博弈论 $\star$

1. `【域】（2）有序域与博弈`
2. `【域】（3）Nim 与公平博弈`、`【域】（4）超现实数与不公平博弈`
